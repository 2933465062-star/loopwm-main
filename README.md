# BiLoop: 轻量化双向循环世界模型

面向小型机器人的轻量化世界模型环境建模与动作预测方法研究。

## 简介

本项目基于循环世界模型（LoopWM）的核心循环动力学，实现了一个约 1M 参数的轻量化双向循环世界模型 **BiLoop**。与单向时序推演不同，BiLoop 同时维护**前向环境推演**与**反向目标回溯**两条循环通路，并通过**软门控机制**依据推理阶段动态调节两路信息的信任度，在仅增加约 3% 参数的情况下提升文本交互环境中的环境建模与动作预测性能。

## 研究问题

在数据受限、模型必须轻量的场景下，结构改进能否在不显著增加参数的情况下提升世界建模能力？

## 核心模块（kernel/recurrent.py）

- **前向循环通路**：沿时序方向推演环境状态的未来演化
- **反向回溯通路**：从目标状态表示（目标嵌入）出发回溯推导当前状态
- **参数共享的双向循环**：前向与反向共用同一个循环单元（一个 GRUCell 复用），不增加参数量
- **软门控融合**：门控网络动态调节两路信息贡献（门控向量 + 隐式互补权重）
- **自适应迭代深度**：训练阶段随机采样迭代次数（1~5，近似泊松），推理阶段固定步数

## 训练协议

- 训练目标：预测观测嵌入与目标状态嵌入（下一观测的编码）之间的 MSE + 动作判别交叉熵
- 反向回溯通路在训练时**显式接收目标状态嵌入**（`state_emb = next_emb`），因此双向循环与软门控均被真实训练，而非退化
- 目标状态嵌入由**固定编码器**在 `torch.no_grad()` 下计算，不参与梯度——本实现为"预编码目标 + 联合微调动力学核"的两阶段式训练，**不属于端到端联合训练**

## 运行流程

```bash
# 1. 生成训练集（ScienceWorld 环境，需要 scienceworld 包）
python loop1.py

# 2. 训练模型
python loop2.py

# 3. 评测：OOD 泛化（EM）
python loop3.py

# 4. 评测：文本指标（Token F1 / BLEU-4 / Entity）
python loop4.py

# 5. 评测：3步束搜索规划
python loop5.py
```

可选环境变量：`SW_TASK`（任务ID，默认 melt-1-2）、`N_EPISODES`（episode数，默认100）、`OUT_PATH`（输出路径）。

## 依赖

- Python 3.9+
- PyTorch 2.x
- scienceworld（训练集生成）
- nltk（文本指标，loop4/loop5 自动下载 punkt）

## 数据集

在 ScienceWorld 文本交互环境上构建专家转移样本（观测—动作对），支持三个代表性任务：

| 任务 | 转移样本 | 唯一动作 | 说明 |
|---|---|---|---|
| 烧水 (boil-1-1) | ~1500 | 7 | 数据质量校验基准 |
| 融化 (melt-1-2) | ~2400 | ~1000 | 复杂动作语义 |
| 冻结 (freeze-1-3) | ~2100 | ~960 | 复杂动作语义 |

## 实验结果（融化任务）

| 指标 | 基线 LoopWM | BiLoop |
|---|---|---|
| EM | 25.0% | 45.0% |
| Token F1 | 39.1% | 44.5% |
| BLEU-4 | 42.2% | 47.3% |
| Entity | 38.0% | 44.9% |
